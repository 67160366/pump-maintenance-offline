# HTML สำหรับนำเสนอ workflow

เปิด `index.html` ใน browser ได้โดยตรง ไม่ต้องติดตั้งหรือเปิด backend และไม่มีการโหลด font/library จากอินเทอร์เน็ต

- 10 ช่วง ใช้เล่าประมาณ 7–9 นาที รวมภายใน LLM อีก 3 หน้า
- ปุ่มถัดไป/ย้อนกลับ หรือปุ่มลูกศรซ้าย/ขวา เปลี่ยนหน้า
- Home / End ไปหน้าแรก/สุดท้าย
- N เปิดคำพูดประกอบ และ F เปิดเต็มจอ (หรือใช้ F11 ของ browser)
- หน้าสุดท้ายมีปุ่มพิมพ์/บันทึก PDF โดยแสดงครบทุกหน้าในโหมดพิมพ์

`original-flow.html` คือแผนภาพ interactive ฉบับเดิมที่บันทึกแยกไว้ ส่วนเนื้อหาฉบับละเอียดอยู่ `../SYSTEM_WALKTHROUGH_TH.md`

ตรวจโครงสร้างและ JavaScript ของฉบับนำเสนอแล้ว: การเปลี่ยนครบ 10 หน้า ขอบเขตปุ่ม คำพูดประกอบ และลิงก์ในเครื่อง ผ่านการตรวจด้วย Node/Python ยังไม่ได้ตรวจ layout ผ่าน browser automation เนื่องจากเครื่องมือปฏิเสธ protocol file://

เนื้อหาอ้างอิงโค้ดปัจจุบันเพื่ออธิบายระบบ ไม่ใช่ผลทดสอบ Pi/GGUF ใหม่

เพิ่มเติม: Tokenizer/embedding, attention พร้อมตัวอย่าง 2 มิติ และตัวอย่าง logits/softmax ที่สลับ grammar และคะแนน A/B ได้ ตัวเลขเป็นตัวอย่างสอน ไม่ใช่ผล GGUF จริง ส่วน HTML ของหน้า LLM เก็บต้นฉบับใน llm-slides.html และรวมไว้ใน index.html แล้ว จึงเปิดออฟไลน์ได้โดยไม่ fetch ไฟล์เพิ่ม
