05 / ภายใน LLM · คำนวณบริบท

Attention รวมข้อมูลจากบริบท
แล้วแปลงผ่าน Transformer 24 ชั้น

แกนคำนวณภายใน attention
Q = XWq · K = XWk · V = XWv
S = QKᵀ / √dₖ + causal mask
attention = softmax(S) V

Q = เวกเตอร์ที่ตำแหน่งนี้ใช้ค้นหา
K = เวกเตอร์สำหรับเปรียบเทียบแต่ละ token
V = ข้อมูลที่นำมารวมตามน้ำหนัก

Causal mask ปิดตำแหน่งอนาคต; RoPE ใส่ข้อมูลตำแหน่งให้ Q/K ก่อนเทียบความสัมพันธ์ สูตรด้านบนย่อ bias ออก

ตัวอย่างคณิตศาสตร์ 2 มิติ ไม่ใช่ activation ของ Qwen จริง
q = [1,0]
k₁ = [2,0] · k₂ = [0,2]

คะแนน = [1.414, 0]
softmax → น้ำหนัก ≈ [0.804, 0.196]

ถ้า v₁=[1,0] และ v₂=[0,1]
ผลรวมถ่วงน้ำหนัก ≈ [0.804, 0.196]

แต่ละชั้น: RMSNorm → Attention + residual → RMSNorm → SwiGLU + residual

GQA: 14 query heads / 2 KV heads · ภาพนี้ย่อหนึ่ง head; ของจริงรวม heads แล้วผ่าน output projection · สถาปัตยกรรมทางการ
